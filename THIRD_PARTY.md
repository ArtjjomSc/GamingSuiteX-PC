# Verwendete Fremdsoftware

GamingSuite X enthält **keinen** fremden Code. Die folgenden Programme werden genutzt, falls vorhanden, bzw. zur Laufzeit von ihrer offiziellen Quelle geladen.

| Software | Verwendung | Lizenz | Quelle |
|---|---|---|---|
| **Intel PresentMon** (Konsolenversion) | FPS-/Frametime-Messung. Wird beim ersten Messen von GitHub nach `%APPDATA%\GamingSuiteX\tools` geladen | MIT | https://github.com/GameTechDev/PresentMon |
| **LibreHardwareMonitor** (optional) | CPU-Temperatur sowie GPU-Temperatur bei AMD/Intel, wenn vom Nutzer gestartet | MPL 2.0 | https://github.com/LibreHardwareMonitor/LibreHardwareMonitor |
| **NVIDIA System Management Interface** (`nvidia-smi`) | GPU-Werte bei NVIDIA, Teil des NVIDIA-Treibers | NVIDIA | wird mit dem Treiber installiert |
| **Flutter** | Android-App | BSD-3-Clause | https://flutter.dev |

Spielnamen und Marken gehören ihren jeweiligen Inhabern. GamingSuite X steht in keiner Verbindung zu Valve, Electronic Arts, Riot Games, Intel, NVIDIA, AMD oder anderen genannten Unternehmen.
